# Architecture

Store proposed and approved architecture records here:

- `domain-architecture/` — domain catalogue and boundaries.
- `data-model/` — conceptual data model and data ownership.
- `security/` — identity, access control, privacy, audit and threat model.
- `localization/` — Amharic-first UX, language, calendar, locale and currency behavior.

Clearly label proposals versus approved baselines. No implementation is authorized by architecture documentation alone.
